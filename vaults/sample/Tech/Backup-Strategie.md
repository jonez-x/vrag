# Backup-Strategie
## 3-2-1-Regel
Drei Kopien der Daten, auf zwei verschiedenen Medientypen, eine davon außer Haus.

## Mein Setup
- Original auf dem Laptop
- Nächtliches Backup mit restic auf die externe Festplatte
- Verschlüsselte Kopie in der Cloud
Wiederherstellung einmal im Quartal testen – ein Backup, das man nie zurückgespielt hat, ist keins.
Betrifft auch das [[Homelab]].
